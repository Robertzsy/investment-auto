# Investment Auto 投资逻辑详解

本文详细说明 Investment Auto 2.1.3 的核心投资智能：**选股逻辑**、**多角色分析流程**、**决策与风控**，以及它们的**商业价值评估**。

> 本文档描述的是"投资逻辑"本身；运行可靠性机制（checkpoint 恢复、幂等回执、密钥存储等）见 [2.0 架构](ARCHITECTURE_2.0.md)。

## 1. 选股逻辑：凭什么认定一只股票比另一只更值得买

设计原则只有九个字：**先排除、再打分、后解释**。选股是确定性代码的两段式流水线，不靠 LLM 拍脑袋。

### 1.1 硬筛选（先排除）

- **代码归一化**：剥离 `sh/sz/bj/hk/us` 前缀统一标的身份，杜绝同一只股票因代码写法不同被重复计算或漏掉；
- **五类硬指标过滤**：最低价、最低成交额、最低市值、PE 上限、PB 上限、单日涨跌幅上限；
- **名单排除**：按名称模式排除 ST/*ST、退市、权证（WARRANT/RIGHT/UNIT/PREFERRED）等；ETF 市场额外排除货币、短融、债券类；
- **拒绝可审计**：每只被剔除的股票都记录拒绝原因。

这一层先挡掉流动性陷阱、退市风险、极端行情与壳炒作——**「不买错」优先于「买得好」**。

### 1.2 六因子加权评分（再打分）

| 因子（权重） | 计算方式 | 回答的问题 |
|---|---|---|
| 动量 momentum（0.28） | 近 5/20 日涨跌幅 clamp 映射 | 现在是否正在走强 |
| 趋势 trend（0.22） | MA5/10/20/60 排列 + MACD 柱 + RSI14 | 中期趋势方向与健康度 |
| 流动性 liquidity（0.20） | 成交额在样本中的百分位 | 买得进、卖得出吗 |
| 估值 valuation（0.12） | PE/PB 历史区间分段 | 当前贵不贵（辅助） |
| 量能 volume（0.10） | 成交量相对变化 | 资金是否在关注 |
| 低波动 low_volatility（0.08） | 近期波动率水平 | 拿得住吗 |

综合分 = Σ(因子分 × 权重)，按分排序取前 N 只（候选池上限默认 30），再经 Agent 复筛输出标准化候选列表。每只入选股都附中文证据，权重与阈值均可配置。

**示例（示意数据）**：股票 A 近 20 日 +8.3%（动量 0.90）、均线多头排列（趋势 0.85）、成交额处样本 92 分位（流动性 0.92）、PE 处历史 45 分位（估值 0.60），加权总分 ≈ 0.81；股票 B 对应得分 ≈ 0.36。A 入选，证据文案形如「近20日上涨8.3%、处于全样本第92分位；均线多头排列；成交额分位92%，流动性充足；PE 处于近三年45分位，估值中性。」

### 1.3 商业价值评估

- **可解释 → 可信赖**：每只入选股带中文理由，用户可复盘「为什么是它」；
- **纪律 → 防踩雷**：排除规则把 ST、流动性陷阱、退市风险挡在门外；
- **零成本 → 边际优势**：筛选是确定性代码，不消耗 token；LLM 只用于复筛与深度分析；
- **可复现 → 可审计**：同一份行情数据永远得出同一张候选名单；
- **可配置 → 可商业化**：因子权重、阈值、排除口径均可配置，支持不同策略风格的产品化封装。

## 2. 多角色分析：一个「该不该买」的结论是怎么产生的

单一模型「看什么都想买」，所以 IA 把机构投研委员会搬进代码——13 个角色、五个阶段。

### 2.1 五阶段与 13 角色分工

| 阶段 | 角色 | 职责 |
|---|---|---|
| ① 基础研究（每标的并行） | 技术面 / 基本面 / 新闻 / 情绪研究员 | 各自维度研究并引用证据 |
| ② 研究辩论 | 多头 / 空头研究员 | 正反方观点交锋 |
| ② 研究辩论 | 研究经理 | 裁决分歧、判定证据充分性 |
| ② 研究辩论 | 交易员（逐标的） | 转成 BUY/SELL/HOLD + 目标权重 + 置信度 |
| ③ 组合草案 | — | 汇总各标的形成组合草案 |
| ④ 风险辩论 | 激进 / 保守 / 中立分析师 | 三方风险视角辩论 |
| ④ 风险辩论 | 风险经理 | 风险裁决与约束 |
| ⑤ 最终决策 | 组合经理 | 最终决策清单（BUY/SELL/HOLD + 权重 + 置信度） |

### 2.2 代码实现

- **原生工作流编排**：整条流水线是 DSH 原生 workflow 脚本（pipeline / parallel / agent），基础研究四路对每只标的并行展开，辩论与裁决按阶段串行推进；
- **schema 冻结 + 组合期预校验**：13 个角色的输出结构冻结为共享常量，插件装载时即做 JSON Schema 校验——结构错误在启动前暴露；
- **证据引用强制**：每条结论必须引用证据（最少 1 条），引用不足的候选被剔除；
- **质量底线**：基础研究成功率低于 80% 时整轮故障安全停止；研究不完整的持仓强制 HOLD、非持仓排除；
- **角色记忆**：每个角色保留结构化记忆（默认 6 条/角色），跨轮次积累个股认知；
- **成本控制**：下游角色只接收压缩后的证据摘要（默认 16000 字符），完整证据落库可回溯。

### 2.3 商业价值评估

- **对抗偏见**：强制空头进场辩论，对冲单一模型的买入冲动；
- **防幻觉**：「结论必须挂证据」让凭空捏造无路可走；
- **该克制时克制**：置信度低于 0.65 不行动、研究不足强制 HOLD——「拿不准就不动手」从口号变成代码；
- **全程透明**：分析流程页展示真实阶段、Agent 进度与证据数量；
- **方法论外溢**：用户每一次使用都在观摩一套机构级投研流程。

## 3. 决策与风控：分析完了，凭什么只能这么买

### 3.1 三档策略授权书

保守 / 中性 / 激进三档，每档定义组合总仓位、现金储备、单票上限、单笔上限、最低置信度、换手上限、每日交易次数、回撤削减与最大回撤等硬边界（默认配置：单票 32%、单笔 38%、单轮换手 35%、置信度 0.65、单轮最多 40 条决策 / 10 笔订单）。边界值永远取代码定义，改文件也改不掉。

### 3.2 执行逻辑

- **仓位封顶**：目标仓位 = min(市场单票上限, 策略单票上限)——A 股市场规则单票 10%，即使策略允许 32% 也按 10% 执行；
- **组合级约束**：单笔金额、单轮换手、现金储备、目标总仓位四道闸；可用资金还受「目标总仓位 − 当前持仓市值」约束；
- **回撤熔断**：回撤触及最大回撤线（A 股 -18%）时强制清仓全部持仓并拒绝一切买入；
- **保护性决策优先于 AI**：硬止损（A 股 -7%）、移动止损（自高点回撤 -4%）、两档分批止盈（+15% 卖 30%、+25% 卖 40%）由代码自动执行，永远排在 AI 建议之前；
- **标的与价格双校验**：只允许交易「持仓 ∪ 最新选股 ∪ 配置默认标的」允许池内的标的；成交价由引擎按实时行情自行抓取，不采用 AI 报价；
- **四市场规则内建**：T+1/T+0、整手、涨跌停、佣金、印花税、滑点全部按各市场真实规则计入模拟撮合。

### 3.3 商业价值评估

- **纪律内置**：止损止盈是代码不是决心，回撤熔断不商量；
- **偏好适配**：三档策略对应不同风险偏好，边界不可被 AI 或用户随手突破；
- **真实成本感**：佣金、印花税、滑点、T+1 全部计入模拟成交，训练出的策略天然考虑摩擦成本。

## 4. 总结

这个产品的价值，不是「AI 帮你赚更多」，而是「把一套可解释、有纪律、可审计的投资决策流程变成人人都能运行的软件」——选股有理由，结论有证据，交易有边界。

> 本项目仅支持研究与模拟交易，不连接真实券商，不构成投资建议。
