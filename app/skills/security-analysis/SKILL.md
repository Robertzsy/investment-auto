# 证券分析（Security Analysis）

## 目标

基于引擎提供的真实数据，对指定证券形成**有数据支撑**的分析结论：趋势、估值位置、风险点、操作倾向（买入/持有/卖出/观望）与置信度。绝不在数据缺失时编造行情或公司事件。

## 数据获取（只允许工具取数）

1. `investment_market_snapshot(symbol)` —— 现价、成交额、均线/动量/MACD/RSI/波动率等指标。
2. `investment_market_history(symbol, lookback=120)` —— 日线趋势与关键位判断。
3. `investment_security_search(keyword)` —— 代码不确定时先搜索确认身份。
4. `investment_macro_latest` —— 宏观与市场背景（必要时）。
5. `web_search` —— 公司公告、新闻、行业动态等事件信息（标注"新闻"性质，不与行情数据混淆）。
6. 若是持仓标的，`investment_portfolio(market)` 查看成本与仓位。

## 分析框架

- **身份核对**：确认代码与名称一致（A股/港股/美股/ETF 代码规则不同）。
- **技术面**：趋势方向（均线排列）、动量（d5/d20）、量能、RSI 是否超买超卖、波动率。
- **事件与情绪**：近期新闻、公告、行业催化；区分"事实"与"市场解读"。
- **风险**：波动水平、事件不确定性、流动性（成交额）、估值位置（若可得）。
- **结论**：给出明确的倾向（BUY/SELL/HOLD/观望）、置信度（0-1）与依据列表。

## 输出要求

结论部分固定包含：

```text
标的：<代码> <名称>（<市场>）
现价：<价格>（<时间>）
技术面：…
事件/情绪：…
风险提示：…
倾向：BUY/SELL/HOLD/观望  置信度：0.xx
依据：1) … 2) … 3) …
数据缺口：<列出拿不到的关键数据；有缺口时必须说明>
```

分析结论若将用于交易决策，必须在用户批准后再通过 `investment_submit_decisions` 提交；单只标的分析本身不改变账户。
