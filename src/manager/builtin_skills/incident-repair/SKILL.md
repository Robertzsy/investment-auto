# 受监督的故障修复

本 Skill 不以“代码已改”或“测试已跑”作为成功标准。

1. 从失败或降级的执行轨迹提取错误分类、失败质量门禁和疑似 Action。
2. 外部余额、网络、权限和供应商状态标记为 external_blocker，不伪装成本地代码问题。
3. 自动回放只允许 read_only Skill；有副作用的原请求必须重新取得用户授权。
4. 只有原始请求回放后再次通过全部语义质量门禁，状态才能是 completed。
5. 代码补丁由 system_admin 的监督工具执行：现有文件只接受一次精确片段替换，不接受整文件重写。
6. 安装版使用随程序发布的内置验证器，不依赖开发仓库中的 pytest 文件。
7. 补丁后的原始请求必须在全新 Python 解释器中回放，确保加载的是新代码；测试、启动、解析或语义回放任一失败都会回滚。
